# graff-wechat-copywriter

![Codex Skill](https://img.shields.io/badge/Codex-Skill-111827?style=for-the-badge)
![Wechat](https://img.shields.io/badge/Graff-WeChat%20Copy-b91c1c?style=for-the-badge)

用于格拉夫高级珠宝微信内容的文案 skill。它面向公众号文章、活动推文、系列介绍和品牌语气检查，强调高级珠宝表达的克制、质感和准确性。

## What It Does

- 生成或优化标题、摘要、首屏 CTA、正文过渡和结尾
- 适合珠宝系列、节日氛围、门店开幕、艺术展览和工艺主题
- 内置品牌语气和标题防重复检查思路
